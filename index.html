    Automation blueprint

    Built as an n8n workflow with the WhatsApp Cloud API. Free group broadcasts replace paid messages wherever possible, to protect the budget.

    1. 1
      Opt-in triggerWeb form or QR code hits an n8n Webhook node with name, number, college, referral code.
    2. 2
      Validate and dedupeIF node checks the number format, then looks it up in the sheet to block duplicates.
    3. 3
      Save the leadGoogle Sheets row with source, referral code and timestamp. This feeds the tracker.
    4. 4
      Confirm and hand out the referral linkTemplate message with the seat confirmation, the personal link and the community group invite.
    5. 5
      Scheduled remindersWait nodes fire at 24 hours, 1 hour and 10 minutes before the session.
