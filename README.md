# NxtWave Growth Intern Challenge

## Build Your First AI Project in 60 Minutes — Growth & Registration Toolkit

This project was created as part of the NxtWave Growth Intern Challenge.

### Objective

The goal is to drive **500 final-year engineering student registrations in 7 days** for the:

**“Build Your First AI Project in 60 Minutes”** workshop

with a **₹2,000 marketing budget**.

---

## Working Asset

This repository contains an interactive growth and registration prototype designed to support the registration target.

### Key Features

- Student registration flow
- Referral-code generation and tracking
- Referral leaderboard
- College leaderboard
- Duplicate/self-referral handling
- WhatsApp registration flow concept
- Reminder-flow design
- 7-day registration growth plan
- 500-registration target simulator
- ₹2,000 budget allocation
- Conservative, base and stretch scenarios
- Funnel and conversion calculations
- AI project ideas for workshop participants
- Growth metrics and tracking concepts
- n8n automation blueprint

The prototype is designed not only as a landing page, but as a **practical growth toolkit** for acquiring, tracking and encouraging student registrations.

## Growth Approach

The core growth strategy combines:

1. **Campus/community distribution**
   - College groups
   - Student communities
   - Peer-to-peer sharing

2. **Referral-driven acquisition**
   - Personal referral codes
   - Leaderboards
   - College-level competition

3. **WhatsApp-led conversion**
   - Registration communication
   - Reminder flows
   - Peer sharing

4. **Tracking and optimization**
   - Registration funnel
   - Referral performance
   - College-level performance
   - Daily registration targets

The intention is to make students not only register themselves, but also become a distribution channel for additional registrations.
